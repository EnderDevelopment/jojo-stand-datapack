# JoJo Stands Minecraft Datapack

JoJoStandDatapack is a Minecraft Java Edition datapack for version 1.20.1 that adds selectable JoJo's Bizarre Adventure Stands, each with two abilities activated by player commands.

## Install

1. Place the project folder containing `pack.mcmeta` and the `data` folder in your world's `datapacks` folder.
2. Load the world and run `/reload`.
3. Run `/function jojo:help` to see the in-game instructions.

This is a world datapack; it does not go in the global `mods` folder.

## Use

1. Choose a Stand with one of these commands:
   - `/function jojo:stands/star_platinum`
   - `/function jojo:stands/the_world`
   - `/function jojo:stands/king_crimson`
2. Activate an ability with `/trigger jojo_ability set 1` or `/trigger jojo_ability set 2`.
3. Check the action bar for your Stand's ability labels and cooldown in ticks.

Star Platinum has a close-range punch and a barrage that damages and slows nearby targets. The World heavily slows nearby entities for five seconds while its user gains speed and haste, and can deliver a heavy area punch. King Crimson grants a short invisibility, speed, and strength burst; its Epitaph ability grants temporary protection and night vision.
